# Security Policy

## Supported Versions

This is a small personal project. Security fixes are currently considered for
the latest state on the default branch only.

## Reporting a Vulnerability

Please do not publish credentials, private aircraft data, or a complete
exploitation procedure in a public issue. If GitHub private vulnerability
reporting is enabled for this repository, use that mechanism. Otherwise open
a minimal public issue asking for a private contact channel and include only
the information needed to reproduce the problem safely.

Reports should include the affected file, environment, impact, and a minimal
reproduction when it is safe to share. There is no guaranteed response time.
